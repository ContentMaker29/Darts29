# Дартс Лига Поморья — Особый случай

Однофайловое веб-приложение: меню и четыре игры для дартс-вечера.

- «Захват мишени» — команды закрашивают сектора, до 11
- «Счёт матча» — 101 / 301 / 501 / 701, леги, пары
- «Bull — кто ближе» — дуэль на центр
- «Набор очков» — раунды на набор
- «Морской бой» — флот на 80 клетках мишени

Результаты сыгранных матчей сохраняются в памяти телефона (кнопка «История матчей»):
их можно посмотреть, отправить в VK через «Поделиться» и очистить.

## Публикация на GitHub Pages

1. Создайте репозиторий (например, `darts-liga`), публичный.
2. Нажмите **Add file → Upload files** и перетащите ВСЁ содержимое этой папки
   (index.html, sw.js, manifest.webmanifest, иконки, .nojekyll).
3. **Commit changes**.
4. Откройте **Settings → Pages**: Source = *Deploy from a branch*, Branch = *main*, Folder = */ (root)*, Save.
5. Через 1–2 минуты приложение откроется по адресу
   `https://<ваш-логин>.github.io/darts-liga/`

## Установка как приложения

- **Android (Chrome):** откройте ссылку → меню «⋮» → «Установить приложение».
- **iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран „Домой“».

После установки приложение открывается без адресной строки и работает без интернета.
История матчей хранится локально на каждом устройстве.
